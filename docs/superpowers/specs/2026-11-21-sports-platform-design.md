# 四路体育赛事回放平台设计（2026-11-21）

用户已确认：保留采集编码；左侧原比例紧凑四宫格，右侧集中控制，底部四轨共用指针；统一启停、场次绑定、时间对齐，默认联动、保留单路检查。

沿用系统 Python/Tk 和已经验收的 NVDEC，不更换节点编码，不动 Jetson 目录。新增纯 Python 赛事时间轴/协调器和独立界面，原四路窗口代码可回退。

## 界面和操作
左侧画面矩阵整体按 2448:2048 缩放，各画面仅含轻量名称/状态叠字，间隙2px。多余宽度给右侧工作区。单击选中、双击放大，Esc 返回。右侧集中赛事选择、全部开始/停止、直播/回放、10/30秒回看、暂停、倍速、逐帧、事件标记、单路高级功能和对齐设置。底部四条录像覆盖轨共享时间刻度及指针，整场自适应，也能缩放/平移。拖动只显示目标，松开执行定位。

## 赛事数据
DGX 保存赛事清单，将四个真实场次目录明确绑定为一场比赛，不以“每台最新目录”代替。历史目录可以组合并保存。元数据建立完整可用区间，空段、缺口、离线明确标识，目标无片段时绝不跳去末段冒充该时刻。

统一轴使用带校准的绝对拍摄时间；UI显示相对赛事起点。节点时钟相对DGX偏差保存为校准值，允许手动微调和用当前帧对齐。历史没有可靠校准时明确提示“未校准”；不能声称硬件同步。校准不重写录像。

## 回放协调
统一seek先暂停所有参与路，异步预取/封装目标片段；全部可用路准备好后同时开始，使用一个单调时钟计算目标播放位置。定位中清除旧图并标注，缺失路不阻塞其余路。最新请求替代旧请求；暂停/倍速/逐帧作用于联动各路，单路检查可临时独立。

## 统一录制
全部开始并发启动未运行的节点，记录每台返回结果及真实场次目录，明确成功数量。全部停止仅确认一次，再并发优雅停止，等待尾段封存并刷新清单；错误按节点呈现，不弹四个归档对话框。停止后仍能完整回放。关闭平台不停止录像。

## 验证和交付
使用四份已录64–65分钟的真实录像验证开头/中间/末尾、跨段、统一暂停/倍速/逐帧、快速重复seek、缺口和单路离线。回归纯时间映射、共享时钟、状态机及场次选择。真实短录测试批量启停并保留原长录像。截图核验常用桌面尺寸，更新桌面入口、部署说明和工作日志。

专业界面参考：Hikvision iVMS-4200 官方手册的多窗口、同步回放和时间轴交互；采用适合本机5MP画幅的布局，不复制品牌素材。
